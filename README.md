# Eskişehir Tarım Akademisi

Eskişehir Valiliği / İl Sosyal Etüt ve Proje Müdürlüğü koordinasyonundaki tarımsal eğitim projesinin web demosu.

Eğitim programları, takvim, eğitim talebi, belge yükleme ve içerik araması.

Demo adresi: https://ozguraric-wq.github.io/tarim-akademisi-demo/

GitHub Pages ön yüzü; talepler ve yüklenen belgeler akademinin ayrı API hizmetinde saklanır. Programlar ve tarihler örnektir.
